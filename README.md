# 🥗 Healthy Food Delivery App

A modern, UI-focused Flutter application that simulates a healthy food ordering experience with a clean, elegant, and scalable structure.

This project demonstrates advanced UI composition, reusable widget systems, and modular Flutter architecture.

## 🎯 Project Objective

The goal of this project is to build a pixel-perfect food delivery interface while focusing on:

* Clean UI structure
* Reusable widget components
* Organized folder architecture
* Smooth navigation flow
* Modern design system

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Khaled-Kamal/Healthy-food-delivery-App.git
```

Navigate to project folder:

```bash
cd Healthy-food-delivery-App
```

Install dependencies:

```bash
flutter pub get
```

Run the app:

```bash
flutter run
```
